# Ecom - Spring Boot E-commerce Application

This project is a full-stack e-commerce application consisting of a Backend (Spring Boot) and a Frontend (Angular). In this repository, the user interface (Frontend) was automatically generated and synchronized primarily using artificial intelligence (AI) tools. The core development focus of the project is on designing the system architecture, implementing services, and optimizing performance in the Backend.

---

## Backend Features and Technical Implementations

The following components and systems have been designed and implemented in the Backend:

### 1. Database and Schema Migration (Flyway)
- Utilized MySQL database to manage products, orders, user accounts, and transaction history.
- Integrated Flyway Migration to version-control the database schema, ensuring smooth and automated schema updates.

### 2. Product & Category Management with Redis Caching
- Developed CRUD APIs for products and categories.
- Integrated Redis Cache (using the Lettuce client) to store product list queries. Search and filter requests are served directly from the cache, reducing database load and improving response times.

### 3. Order Processing and VNPay Payment Gateway Integration
- Implemented full workflows for orders and order details.
- Integrated VNPay Sandbox gateway for online payments, handling redirection, secure callback hashing, and automated order status updates based on payment results.

### 4. Coupon System using Entity-Attribute-Value (EAV) Model
- Designed a flexible database structure based on the EAV architectural pattern to support dynamic coupon conditions (e.g., discounts based on minimum order value, specific product categories, etc.).
- Developed the core discount calculation engine.

### 5. Aspect-Oriented Programming (AOP) Logging and Asynchronous Messaging (Kafka)
- Used AOP to build performance logging aspects that automatically measure execution times of controllers and services without cluttering business logic.
- Integrated Apache Kafka to handle asynchronous events, such as publishing events when new categories are created, decoupling systems and reducing API response latency.

### 6. Product Comments, Favorites, and Internationalization (i18n)
- Implemented comment and product favorite systems mapped to user accounts.
- Integrated multi-language support (i18n) for English (en) and Vietnamese (vi) languages to localize error messages and API responses.

### 7. Security, Authentication, and API Documentation
- Configured Spring Security with stateless JWT (JSON Web Token) authentication, including secure refresh token workflows.
- Implemented OAuth2 social login integration supporting Google and Facebook logins.
- Integrated Swagger UI / OpenAPI for automated API documentation.
- Configured Spring Boot Actuator health check endpoints for application monitoring.

## Frontend Application (Angular)

The frontend client is built with Angular v19 and Bootstrap.
- The user interface was automatically generated by AI tools, mapped from the API responses designed in the backend.
- Configured and optimized to resolve hydration mismatches under Server-Side Rendering (SSR) environments, successfully pre-rendering 15 static routes during the production build.

## Local Development Setup

### 1. Prerequisites
- Java Development Kit (JDK) 21.
- Node.js (version 18 or above) with pnpm package manager.
- Docker Desktop.
- MySQL Server (running locally or via Docker container).

### 2. Start Infrastructure Services (Redis & Kafka)
Run the following command at the project root to spin up Redis and Kafka containers:
```bash
docker compose -f docker-compose-infra.yml up -d
```

### 3. Start the Backend Server
Navigate to the backend directory and run the Spring Boot application:
```bash
cd ecom_be
$env:SERVER_PORT="8088"
.\mvnw.cmd spring-boot:run
```
The backend API will be available at: http://localhost:8088/api/v1

### 4. Start the Frontend Application
Navigate to the frontend directory, install dependencies, and run the development server:
```bash
cd ecom_fe
pnpm install
pnpm run start:dev
```
The frontend client will be accessible at: http://localhost:4300/
